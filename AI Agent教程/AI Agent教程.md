# AI Agent(智能体) 教程

AI Agent（Artificial Intelligence Agent，智能体）：本质是自动执行任务的程序，核心在于让模型不只回答问题，而是按步骤完成动作。

Agent = LLM (大脑) + Planning (规划) + Tool use (执行) + Memory (记忆)。

AI Agent：

- 理解任务目标：明白你想要什么结果
- 制定计划：思考如何达成目标
- 使用工具：调用各种资源和 API
- 自我调整：根据反馈优化策略并记录
- 持续执行：直到完成任务或遇到无法解决的问题

工作流程：输入 → 思考 → 调用工具 → 执行 → 返回结果 → 持续迭代



AI Agent 核心组件（以餐厅为例）

- **大脑：**负责听懂点单、判定目标、决定顺序，是餐厅的指挥中心。
- **工具：**负责实际动手，包括切配、烹饪、采购等动作，把决策转成可执行操作。
- **记忆：**负责记录顾客偏好、当前步骤、已处理内容，保证流程不混乱、不重复。
- **规划：**负责把整道菜拆成步骤，确定先后关系，确保任务按流程推进到完成。



术语

| 术语                              | 中文           | 核心含义                              |
| :-------------------------------- | :------------- | :------------------------------------ |
| **Prompt**                        | 提示词         | 给模型的输入指令                      |
| **Skills**                        | 技能           | Agent 可调用的专项能力模块            |
| **MCP**（Model Context Protocol） | 模型上下文协议 | Agent 连接外部工具/数据源的标准化协议 |
| **Context**                       | 上下文         | 当前任务可获取的信息范围              |
